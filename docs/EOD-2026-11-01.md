# Recalls Tutor — EOD Update, 1 November 2026

## Summary

The core content-to-student workflow is now built end to end: staff upload raw recalls, Claude drafts exam-style questions, a human reviews and publishes them, and students practise them. All automated tests (8 of 8), the type check and the production build pass. The live Claude drafting run is still pending a one-time sign-in on the demo machine.

## Completed today

- **Authentication verified.** Integration tests pass for signup, email verification, login, two-factor authentication, recovery codes, password reset, session revocation and rate limiting. A cross-site request protection gap in the auth library's test mode was found and fixed.
- **Student practice built and browser-tested.**
  - Revision Mode gives instant feedback: correct answer, explanation, references and how other students answered.
  - Exam Mode has a server-enforced timer, navigator, flags, automatic saving and automatic submission when time runs out.
  - Results, a mistakes deck and confidence tagging are in.
  - Questions are watermarked with the student's email and account ID.
  - Only published questions are ever shown, one at a time.
  - Works at 360 px phone width.
- **Recall AI Studio with Claude built.** No API key is needed; it uses the Claude account login.
  - Upload a chat export or text file, or paste text.
  - Names, phone numbers, emails, mentions and links are removed automatically before anything is stored or sent to Claude.
  - Claude drafts five-option questions with explanation, key notes, references, topic, difficulty and a confidence score.
  - Low-confidence drafts, unverified references and likely duplicates are flagged.
  - Reviewers can edit, ask Claude to refine with instructions, reject, approve and publish.
  - AI can never publish; every action is audit-logged.
- **Meeting demo prepared:** a separate demo database with ready staff and student accounts, a synthetic sample chat export (fake names, noise, a duplicate and a planted malicious instruction), and a step-by-step demo script.
